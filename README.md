# ❄️  HVAC 진단·현장 지원 도구 개발

Coollab은 공조냉동 설비의 점검과 유지보수를 수행하는 현장 엔지니어를 위한 웹 기반 HVAC 진단·현장 지원 도구입니다.
냉매 압력과 온도 측정, 냉매 P-T 데이터 확인, 제조사별 에러코드 검색, 현장 작업 기록 및 점검 보고서 작성​까지 현장에서 자주 사용하는 기능을 하나의 화면에서 사용할 수 있도록 설계했습니다.

## 💻 기술 스택

- HTML5
- CSS3 & SCSS
- JavaScript
- React
- Git
- Tailwind css

##👨‍🔧 Target Users

Coollab은 특히 다음과 같은 사용자를 대상으로 합니다.

- HVAC 엔지니어
- 냉동·공조 유지보수 기사
- 에어컨 설치 및 서비스 기사
- 시설관리 엔지니어

## ⚙️ 주요 기능

- 냉매 측정 및 진단 : 현장에서 측정한 데이터를 입력하여 냉동사이클의 기본 상태를 확인
- Superheat / Subcooling 계산 : 냉매의 압력과 온도 데이터를 기반으로 다음 값을 계산합니다.
- 냉매 P-T 데이터 : 냉매의 압력과 포화온도 관계를 확인
- 제조사별 에러코드 검색
- 현장 작업 기록 : 현장에서 수행한 작업을 기록하고 보고를 할 수 있습니다.
- 페이지 당 5개의 문항 출력
